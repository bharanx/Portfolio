CHAINPROOF

Evidence-Based Verification of Software Supply-Chain Integrity

OVERVIEW

ChainProof asks one specific question: which combinations of code signatures, build provenance (SLSA), software bills of materials (SBOMs), and reproducible builds actually catch tampering in an open-source software supply chain — and which just look secure without doing much. It's built as a research project first: a testable question and a threat model, not a tool demo.

PROBLEM STATEMENT

Software supply-chain attacks — tampered dependencies, compromised build pipelines, poisoned containers — are an increasingly common way real breaches start, and most verification methods get adopted without being tested against actual tampering scenarios.

APPROACH (PLANNED)

Build a source-to-artifact evidence chain covering commit, build, and artifact stages. Generate SBOMs (starting with Syft), verify build provenance against the SLSA framework, and check build reproducibility — then measure what each layer actually catches versus misses, against a labelled set of tampering scenarios.

EXPECTED OUTPUT

An open-source verifier, a labelled tampering benchmark, and reproducible experiment results.

STATUS

Just started — August 2026. No code or results yet. This section will be updated with a repo link, real findings, and data as the project develops.

NETRA

Portable Network Security Device for Public Wi-Fi Protection

OVERVIEW

NETRA is a portable, plug-and-play network security device designed to provide an additional layer of protection when using public or untrusted Wi-Fi networks. It monitors network traffic, identifies suspicious activity and potential security threats, blocks detected threats, and provides security alerts through a web-based dashboard.

PROBLEM STATEMENT

Public Wi-Fi networks can expose users to network-based threats such as man-in-the-middle attacks, suspicious connections, port scanning, and unknown network activity. Conventional users often have limited visibility into what is happening within the network while they are connected, making it difficult to identify or respond to potential threats in real time.

APPROACH

NETRA operates as an intermediary between the network router and the user's system, allowing network traffic to be monitored and inspected for suspicious activity. Detected threats are evaluated and appropriate traffic-blocking actions can be applied, while security events are communicated through the NETRA web dashboard for real-time visibility.

KEY CAPABILITIES

  • Network traffic monitoring and inspection
  • Detection of potential man-in-the-middle activity
  • Port scanning detection & suspicious IP identification
  • Threat blocking and real-time security alerts
  • Web-based security monitoring dashboard
  • Portable deployment for public or untrusted Wi-Fi

EXPECTED OUTCOME

A portable network security solution that improves visibility into network activity and provides users with an additional layer of threat detection, blocking, and alerting when operating over public or untrusted Wi-Fi.

STATUS

College project — prototype and web dashboard developed. The project demonstrates the concept of portable network monitoring, threat detection, automated blocking, and security alerting.
